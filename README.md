# 国科大杭州高等研究院报考指南

非官方公益报考指南，介绍**国科大杭州高等研究院（杭高院）**及其二级学院，汇总报考、复试、培养与上岸经验。内容依据官方公开信息与考生经验整理，仅供参考，请以官方发布为准。

## 目录结构

```text

│  ├─ index.md                 # 简介栏目落地页（杭高院概况）
│  ├─ 经验分享投稿模板.md

│  ├─ 整体介绍.md
│  ├─ 招生专业/                # 招生专业
│  │  ├─ 085404计算机技术.md
```

## 怎么用

1. 把资料放进对应文件夹：
   - 杭高院整体信息放 `简介/`
   - 智能学院信息放 `智能学院/`
   - 物光学院信息放 `物理与光电工程学院/`
   - 经验贴放 `智能学院/上岸经验分享/`，一个经验贴一个 `.md` 文件
2. 运行构建脚本：

```powershell
powershell -ExecutionPolicy Bypass -File .\build-site.ps1
```

```bash
bash build-site.sh
```

3. 本地预览：

```powershell
python -m mkdocs serve
```

打开 <http://127.0.0.1:8000/>。

脚本会自动扫描各栏目下的 Markdown 文件并生成导航（栏目与页面顺序见 `update_nav.py` 中的 `SECTIONS` / `NAV_ORDER`）。首页「上岸经验分享」卡片由 `update_homepage.py` 在构建时自动生成。

## 内容约定

- **搜索不到的栏目请留空并标注「🚧 待补充」**，方便后续补充，避免误导。
- 信息请尽量注明来源或标注「以官方发布为准」。
- 想匿名展示学校时，把学校名加入 `anonymize.py` 的 `REPLACEMENTS`，构建时会在 `docs_src/` 副本中自动替换，仓库源文件不受影响。

## 部署

构建产物在 `site/`，可直接部署到 GitHub Pages、Cloudflare Pages 等静态托管。
