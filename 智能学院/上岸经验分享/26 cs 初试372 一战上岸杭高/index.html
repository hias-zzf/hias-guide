    26 cs 初试372 一战上岸杭高

    鼠鼠上圣杭高？26 CS 初试372 最后惊险过线 先介绍一下自己，俺是一只本科某末流211 + 三无人员 + 基本上爽玩了本科三年（大学一共下来steam打 了1.7k小时游戏） + 想努力却没有好成绩的鼠鼠 不知道说啥好？一直在酝酿着自己的情绪（最近被毕业论文的事搞得焦头烂额的 先简单地点评一下自己 26考研的成绩吧

    数学113 408 111 英语 80 zz 68¶

    其实这个成绩说好也没多好，说差也没多差（还好抄底了CS[bushi] 今年的数学很简单，但是自己没把握住，最后微分方程和线代那里扣了大分，大概15分是有的，选填又 错了10分，剩下的11分有的是在前面的大题里算错了结果。。。数学咋说呢，还是得好好练的。。。做 题这方面还是落下了，不过还好苟运苟住了 英语的话，从高中开始鼠鼠的英语就比较强，上了大学也基本上是在吃老本，最后一直吃到了考研（汗 流浃背了，后面会分享一些学英语的经验。 政治嘛，有些出乎意料，可能是今年京区没咋压分，肖四今年好像押中了一些，但还好，中规中矩。 408的话...难度就在那里了，鼠鼠认为是偏难一点的，后面也会详细地总结一些个人的学习经验和博主推 荐。 初试准备

    数学¶

    有人说，蓝开前期弱后期强，红开前期强后期乏力，那么问题来了，鼠鼠是蓝开后期转到红开hhhh 单 纯做个调侃（其实鼠鼠很想吐槽张宇的书，在前期说实话看着会很吃力。。。 其实红开跟蓝开都行，但是问题在于本科前期对高数的掌握程度并不是特别好，这就导致你在备考初 期可能会遇到相当吃力的情况，考研数学的学习曲线在一开始是很陡峭的，很多人都是在前期没有重视 好一些正确的学习方法（比如鼠鼠）导致后期要做的事更多，基础不牢，地动山摇的情况十分常见。 为此，十分建议在前期（3月-6月末）做好以下几点： 好好地把辅导书过一遍（不管红开还是什么的） 多做题多做题（听一讲就做一讲题目，错的题好好进行复盘 可以看看一些博主的数学大观，把整体的架构给搭建好再去一点点地做填充，框架搭好了就知道自 己要做什么了 关于做题，可以看看武老师的每日一题，在保持手感的同时还可以让自己看一下自己应该到什么进度 了，争取超过武老师每日一题 2-∞ 个章节（按照自己的实际情况来），线代方面可以强烈推荐没咋了的 线代基础。概率论？数二不考概率论捏；关于大观，它是一个需要不断积累的过程，这里推荐一些博 主，比如帕拉迪宇的大观。 暑假期间鼠鼠是在学校图书馆学习的，当时鼠鼠是在做🐙的强化阶段的书，鼠鼠感觉他的高数部分还 行，但线代部分并不是特别好，这时候一定要上B站搜索没咋了的线代强化课，真的听完一下子就理清了 乱七八糟错综复杂盘根错节的知识框架。习题的话，有空也可以多做做880，这本书还是很不错的。 到了9月份开学，一直到11月份就一直在做真题了，刷套卷一方面一定要控制好时间（3h），狠狠地 拷打自己，只有做了套卷才知道自己到时候在考场上会是一个怎样的状态。晚上留一部分时间好好复 盘。模拟题的话，张四张八就做了前面几套，有几套题出得很水；25超越的选填是很考验计算能力的， 可能一校对会发现自己错一堆 遇到难题不要气馁，有些模拟卷出来就是要来锻炼你的抗压能力的，调整 No. 1 / 3 好状态好好复盘就行。同时，闲暇之余可以去看看你的葫芦这个B站up主，他的有些解题思路很让人叹 为观止。 从12月份到考前，这段时间好好地翻翻做过的真题、模拟卷，同时也可以看看你的葫芦的一些考前押 题。不过不多说，鼠鼠最后考得也挺烂的其实（，因为线代和微分方程那里扣了大分，所以一定要重视 前中期的积累！ 不错的经验贴 https://zhuanlan.zhihu.com/p/684460316 恩师氧气（强推），无需多言。（打广告来了） 408直接跟着氧气学没毛病（鼠鼠只跟了他，所以对其他的老师并不是特别了解），从头到尾，一个月 充电25块钱，3-12月，9个月，225块钱，性价比太高了，而且还可以接触到隔壁的一些不错的408题 目。像学习规划什么的，也可以按照氧气的课程进度来就好了

    2. wd的选择题鼠鼠个人认为出得简直就是灾难（ 有些地方跟阅读理解一样让人感到云里雾里的，推 荐另外一本题集，relax团队的1000题，可以用来作为强化阶段的题集，做完好好复盘之后会有不 错的收获的。

    4. 最后就是真题刷题了，真题一定要反复做几遍，即使一眼看出答案也要好好地想一下它背后涉及到 的知识点和一些流程

    英语¶

    英语，老生常谈的问题：背单词，每天尽量背100个左右，用墨墨背单词里的红宝书，一直背到考前就 好。 阅读方面，刷题，这方面一定要注重理解，咬文嚼字地去把握好它这个问题的意思。把04-25年的阅读 题都做一遍就可以上考场了。 作文方面，上模板吧，鼠鼠作文水平也是稀拉.....模板小红书，B站都可以找，考前练个大概20篇大作 文，10篇小作文就可以了

    政治¶

    政治的话，鼠鼠是在暑假期间就开始看徐涛的马原课，当作每日的一个小甜点挺不错的，徐老师也会 在课中给你讲不少有意思的例子。看马原的目的是为了更好地理解它一些晦涩的概念，但是有把握的话 也可以不用看（注意判断有把握的标准是掏出一个马原概念和一个解释，你能看懂）。 选择题方面，鼠鼠忘了鼠鼠是九月份还是十月份开始的，反正当时鼠鼠是在一些考研小程序做的选择 模拟题，一直刷到考前，政治选择题能拿个40分左右了，10月份是在墨墨记忆卡上看帕拉迪宇的一页 纸，每天半小时，能看多少就看多少。大题方面，鼠鼠是背了考研大李子出的政治一页纸，在肖四出来 之后就一直在背肖四，因为前面背了大李子的一页纸，所以后面比较轻松，每天早上蹲在图书馆的一个 角落里背大概1个半小时左右。今年的肖四还是被它压到了不少题目的，不赖。哦对，还有考研大牙的考 前抄材料教程hhhh，这个也可以看看 No. 2 / 3

    复试¶

    复试没什么太多好说的，好好准备就完事，好好整理自己的履历，老师不会太为难你的，努力就该有 回报！ 最后一些碎碎念 收到拟录取通知的时候鼠鼠还在床上睡大觉，醒来懵圈了hhhhh，一下子就陷入了很emo的状态，鼠 鼠呀，也是能上杭高了 鼠鼠还记得刚下定决心考研的状态：迷茫，无知。不知根本从哪里开始，翻了一篇又一篇的经验贴和 杭高学长学姐们的经验贴，很感谢这些帖子给了当时的鼠鼠足够的信息和信心。最后鼠鼠一不做二不 休，直接选择了圣杭高作为心仪的院校，解决了整天悬在空中、一直在消耗鼠鼠的迷茫。 刚开始学习的时候，鼠鼠会很累，学了忘、忘了学，反反复复，总感觉自己在原地踏步。一定要记 住，考研是自己的事，没必要跟别人比进度，好好学自己的就完事。 到了暑假那会，身边人都在旅游、潇洒地挥霍青春的恣意，还好鼠鼠有个好麻吉，一直陪着鼠鼠走到 他保研那天，也算是鼠鼠有福气！不过鼠鼠也是体会着一种无法言说的痛苦，这种感情不知从何而起， 也不知该往哪里倾泄，不过好在鼠鼠有好麻吉，谢谢他们。同时鼠鼠也想说，如果你也在经历这些情 绪、这些感情，一定一定要记得，你不是太矫情，也不是太脆弱，它值得被重视，你在这个过程中不断 地认识自己，和自己和解。一定要好好吃饭！关注好自己的健康！ 一路波折，鼠鼠的考研回顾也差不多到这里了，在这里鼠鼠也祝往后考研的学弟学妹顺利上岸！ 倘若没有这一路的辛酸，我们是记不住这段岁月的 No. 3 / 3
