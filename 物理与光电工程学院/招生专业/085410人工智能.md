# 085410 人工智能

**085410 人工智能**（专业型硕士）是物理与光电工程学院的招生专业之一，2026 年设有 **02（小卫星联培）**、**03（智能光电）** 两个方向。

| ---------------- | ----------------------------------------------------------------------- |
| 专业代码         | 085410                                                                  |
| 专业名称         | 人工智能                                                                |
| 所属学院         | 物理与光电工程学院（物光学院）                                          |
| 研究方向（2026） | （02）小卫星联培；（03）智能光电                                        |
| 考试科目         | ①101 思想政治理论 ②204 英语（二）③302 数学（二）④408 计算机学科专业基础 |


## （02）小卫星联培

**（02）中国科学院微小卫星创新研究院联合培养专项：人工智能（航天工程方向、通信工程方向、空间机器人方向）**，是 085410 人工智能在**物理与光电工程学院**设置的方向之一。

该方向由**中国科学院微小卫星创新研究院**与杭高院**联合培养**，方向内容涉及航天工程、通信工程、空间机器人等。具体培养模式、导师与科研方向 *待补充*。

???+ tip "人工智能其它方向都可以选小卫星联培的导师"
    2026年以及之前，人工智能 （01 ~ 03）都可以选择小卫星联培，包括**智能学院**的人工智能（01）

## （03）智能光电

**（03）智能光电感知信息处理**，是 085410 人工智能在**物理与光电工程学院**设置的方向之一。

该方向聚焦**智能光电感知与信息处理**，结合光电探测与人工智能技术。具体科研方向、导师团队与培养方案 **待补充**。

## 特殊计划

杭高院硕士招生除普通统考外，还设有**少数民族高层次骨干人才计划（少干计划）**和**退役大学生士兵专项计划（士兵计划）**两类特殊计划。两者均**单独划定复试分数线、招生计划单列**，不占用普通统考名额；报考条件、资格审核与享受政策各不相同，具体以当年教育部及国科大官方通知为准。

??? info "杭高院所有学院，同一个专业代码的内部共享名额"
    人工智能和隔壁 **[智能学院](../../智能学院/招生专业/085410人工智能.md)** 共享名额，包括分数线。实际录取名额由**国科大**分配到各二级学院。

!!! warning "招生简章录取人数注意"
    往年并没有给出实际的招生简章招生名额，最后录取会从杭高院分配的名额动态调整。

### 少干计划（少数民族高层次骨干人才计划）

**面向少数民族考生**（部分在民族地区工作的汉族考生也可报考，比例有限制）的专项招生计划，实行「**定向招生、定向培养、定向就业**」：报考前须经生源地省级教育行政部门审核，**<font color="red">毕业后须回生源地（定向地区/单位）就业服务一定年限。</font>** 复试线一般明显低于普通计划，就读期间的学费、奖助等以国科大当年规定为准。
